## Question 01
What is deployment and why do we do it?

### Solution
Deployment means making the application run on a server so users or clients can access it. We use Docker or a web hosting service to make the app available outside the local machine.

### Example
A FastAPI app is packaged into a container and exposes port 8000.

### Expected Output
A running app reachable over HTTP, for example `http://127.0.0.1:8000/docs`.
